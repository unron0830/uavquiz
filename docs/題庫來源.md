# 題庫來源與使用說明

本專案包含無人機操作證題庫的整理資料及教學解說。題庫不會自動同步主管機關更新；考試規定與答案以最新官方公告為準。原始題目與引用素材的權利歸各原權利人，本專案不替原始題庫或第三方圖片重新授權。發現疑義請附題號及官方依據到 GitHub Issues 回報。
